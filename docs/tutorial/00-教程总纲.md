# BigWorld Engine 14.4.1 深度教程·总纲

> 本教程深入探索 BigWorld Engine 14.4.1 的实现,从架构总览到源码细节,共 20 章,面向 MMOG 开发新手,由浅入深。

## 教程定位

- **读者**:熟悉 C++/Python,但不了解 BigWorld 的 MMOG 开发新手
- **深度**:每章 800-1500 行,包含原理、代码引用、设计权衡、特色实现
- **重点**:架构设计、分布式与网络通信、源码实现细节、工具链与工作流、特色实现方案
